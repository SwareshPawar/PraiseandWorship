🧹 Mood Data Cleanup Tool

🎯 Purpose

This tool fixes inconsistent mood data in your database where some mood arrays contain comma-separated strings as single elements.

Example Problem: ["Thanksgiving", "Love", "Happy, Christmas, Easter"]

Fixed Result: ["Thanksgiving", "Love", "Happy", "Christmas", "Easter"]

⚠️ Important

Always run a dry run first to see what changes will be made before applying them to your database.
