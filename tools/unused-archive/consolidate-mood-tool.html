🔗 Mood Field Consolidation Tool

🎯 Purpose

This tool consolidates all mood-related data into a single standardized field and removes redundant fields.

What it does:

  • ✅ Merges data from mood, moods, and mood tags in genres
  • ✅ Creates single mood field in frontend-compatible format
  • ✅ Removes redundant moods field completely
  • ✅ Cleans mood tags from genres field
  • ✅ Ensures no mood data is lost during consolidation

⚠️ CRITICAL - Before Running

Prerequisites:

  1. 🔐 Must be logged into main app first (same browser session)
  2. 🖥️ Backend server must be running on localhost:3001
  3. 💾 Database backup recommended before running consolidation

📝 Example Transformation

Before consolidation:

mood: ["Thanksgiving", "Love", "Happy, Christmas, Easter"] moods: ["Dance", "Action"] genres: ["Worship", "Christmas", "Praise"]

After consolidation:

mood: "Action, Christmas, Dance, Happy, Love, Thanksgiving" genres: ["Worship", "Praise"] // moods field removed completely
