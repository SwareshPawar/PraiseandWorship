🔄 Mood Migration Tool

ℹ️ What this tool does:
This migration script will move mood-related tags from the "Genres" field to the new "Moods" field in your database.

Tags to be moved: Dance, Patriotic, Christmas, Easter, Action, Forgiveness, Thanksgiving, Good Friday, Holy Spirit, Love, Qawalli, Miracle

✅ No authentication required - Script will run directly against your local database.
⚠️ Important: Always run the "Dry Run" first to preview changes before performing the actual migration.
